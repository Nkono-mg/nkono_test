 Projet Nkono Test
 Partie Backend
▶ Lancer le serveur Node.js
cd nkono_test/nodejs
npm run dev

 API Endpoints
🔹 Récupération de la liste des logs
GET http://localhost:5000/api/logs/all

🔹 Filtrer les logs par date
GET http://localhost:5000/api/logs/bydate

 Partie Frontend
▶ Lancer le serveur React
cd fronted
npm start

Le serveur démarre par défaut sur :
👉 http://localhost:3000
